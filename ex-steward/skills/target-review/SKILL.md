# Skill: target review

Use this skill for review, validation, and regression checks.

## Review checklist

- Confirm the change matches the request.
- Check the diff for unrelated edits.
- Validate the changed behavior with the smallest relevant proof.
- Inspect test, build, or runtime output for failures.
- Record whether anything remains unverified.

## Decision rule

If the evidence is weak or partial, report the task as partially verified, not complete.
