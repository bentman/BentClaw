# AzureClaw — OpenClaw on Azure (Terraform)

Deploys [OpenClaw](https://openclaw.ai) on a single Azure Linux VM. No Bastion, no Key Vault — just a locked-down VM with a public IP and NSG-restricted SSH.

## What you get

| Resource | Details |
|---|---|
| Resource Group | `rg-<project_name>-<location>` |
| VM | `Standard_B2s` (2 vCPU / 4 GB, burstable), Ubuntu 24.04 LTS, 128 GB Standard SSD |
| Networking | VNet `10.0.0.0/16`, VM subnet `10.0.2.0/24` (VM static at `10.0.2.8`) |
| NSG | SSH (22) locked to **your** public IP (auto-detected); OpenVPN (UDP 1194) open to public; gateway port optional |
| Public IP | Standard SKU, static, FQDN `<project_name>008.<location>.cloudapp.azure.com` |
| SSH key | Generated by Terraform, output as `ssh_private_key` |
| OpenVPN | peer-fingerprint mode server on the VM; `azureclaw.ovpn` written to the VM home dir |
| Software (cloud-init) | OpenClaw (latest, official installer), azure-cli, ffmpeg, openvpn, git, curl |

OpenClaw is installed on first boot via cloud-init running the official installer with `--no-prompt --no-onboard`: non-interactive, latest version (npm global install), **no onboarding and no gateway start**. Run `openclaw onboard --install-daemon` yourself when you're ready.

**Estimated cost: ~$35/month** (VM ~$30, disk/IP minor). `terraform destroy` or deallocate the VM to stop compute billing.

## Prerequisites

- Terraform >= 1.6.0
- Azure CLI authenticated (`az login`)
- Resource providers registered (one time):
  ```
  az provider register --namespace Microsoft.Compute
  az provider register --namespace Microsoft.Network
  ```

## Deploy

```bash
cp terraform.tfvars.example terraform.tfvars   # fill in the ARM/sp values
terraform init
terraform apply
```

## Connect

```bash
terraform output -raw ssh_private_key > ~/.ssh/openclaw_key.pem
ssh -i ~/.ssh/openclaw_key.pem <vm_localadmin_user>@$(terraform output -raw vm_public_name)
```

`~/.ssh/openclaw_key.pem` works in both bash and PowerShell and inherits ACLs on Windows. If you save the key somewhere else on Windows, restrict its ACL (`icacls <file> /inheritance:r /grant:r "<DOMAIN>\<user>:R"`) or OpenSSH will refuse it ("UNPROTECTED PRIVATE KEY FILE").

## Verify

Wait ~10 minutes for cloud-init (apt upgrade + OpenClaw install), then in the VM:

```bash
tail /var/log/cloud-init-output.log
openclaw --version
openclaw doctor
```

When ready, finish setup interactively:

```bash
openclaw onboard --install-daemon
```

## Access the gateway

The VM runs an OpenVPN server (peer-fingerprint mode, generated on the VM with openssl at first boot) on UDP 1194, open to any public IP. Fetch the profile after cloud-init finishes:

```bash
terraform output -raw openvpn_config_file   # prints the scp command
# backup option: 
ssh -i ~/.ssh/openclaw_key.pem <vm_localadmin_user>@$(terraform output -raw vm_public_name)  
cat ~/azureclaw.ovpn > azureclaw.ovpn  
```

Import `azureclaw.ovpn` into OpenVPN Connect (or `openvpn --config azureclaw.ovpn`).  
Once connected, the gateway is reachable on the VM itself:

```bash
echo "http://$(terraform output -raw vm_private_ip):$(terraform output -raw gateway_port)"
```

Only the VM is reachable over the tunnel — not the whole subnet. Note: the OpenClaw gateway must be listening on a reachable interface (default bind is `127.0.0.1`; relax it to reach it over the VPN).

Or set `allow_gateway_public = true` in `terraform.tfvars` to allow the gateway port from your IP directly (re-apply required).

## Cleanup

```bash
terraform destroy
```

## Outputs

| Output | Description |
|---|---|
| `resource_group_name` | Name of the resource group |
| `vm_public_ip` | Public IP address of the VM |
| `vm_public_name` | Public DNS name (FQDN) of the VM |
| `vm_private_ip` | Private IP of the VM (gateway target over VPN) |
| `ssh_private_key` | SSH private key for the VM (sensitive; save to `~/.ssh/openclaw_key.pem`) |
| `ssh_command` | Ready-to-use SSH command (sensitive) |
| `openvpn_port` | OpenVPN server port (UDP) |
| `gateway_port` | OpenClaw gateway port |
| `openvpn_config_file` | scp command to fetch `azureclaw.ovpn` (sensitive) |
| `next_steps` | Post-deploy checklist (sensitive) |

## Sizing notes

- `Standard_B2s` is the sweet spot for a single-user, bursty OpenClaw workload (~$30/mo).
- Heavier use (multiple channels, big automations): 
  - bump to `Standard_B2as_v2` (2 vCPU / 8 GB, ~$55/mo) — the size used in the official docs.
- cloud-init runs `apt update && apt upgrade -y`, installs packages, then installs OpenClaw (npm global) and `npm update -g`; first boot takes ~10 minutes before everything is up.
